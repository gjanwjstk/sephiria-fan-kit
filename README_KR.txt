구성
  Screenshots/             공식 상점 스크린샷 (보도용)
  Gifs/                    짧은 플레이 영상 루프 (전투/대화/인벤토리)
  Logo/                    게임/팀 로고 (1x/2x/4x)
  KeyArt/                  홍보용 키아트 / 배경화면
  Brand/                   컬러 팔레트 + 폰트 크레딧(폰트 파일 미포함) + 앱 아이콘
  Artifacts/  (309개)
    Icons/ 1x 2x 4x 8x     투명 픽셀 아이콘(기본)
    Framed/ 1x 2x          64px 등급 테두리 + 배경 버전
  Tablets/    (66개)      석판, 동일 구성
  Weapons/    (169개)      무기, 동일 구성
  Potions/    (29개)       포션/소비 아이템, 동일 구성 (+ potion_index.csv)
  Miracles/   (16개)       미라클 아이콘 (+ miracle_index.csv)
  Keywords/                스탯/상태 키워드 아이콘 (+ keyword_index.csv)
  Categories/              아티팩트 결속/카테고리 아이콘 (+ category_index.csv)
  Costumes/                플레이어 코스튬 전체 스프라이트 (+ costume_index.csv)
  FruitSkewer/             결속 과일꼬치 아이콘
  FaceChips/               캐릭터 대화 초상화
  Steam/                   스팀 상점/라이브러리/이벤트 아트 (Jon)
  Effects/                 인게임 효과 텍스트, 언어별 .txt
        AllItemEffects_*    아티팩트/석판/포션
        AllWeaponEffects_*  무기, 강화 트리 형태
        ComboEffects_*      결속/카테고리 콤보 효과
        WeaponActions_*     기본 무기 좌클릭/우클릭 액션
  artifact_index.csv / tablet_index.csv / weapon_index.csv
        파일명 -> 아이템 id, 등급, EN/KR 표시명, EN/KR 효과 텍스트
        weapon_index.csv에는 강화 트리도 열로 들어갑니다:
        tier(1~3), upgrades_from(상위 무기 id), upgrades_to(하위 무기 id들)

참고
  - 파일명은 인게임(영문) 이름 기준입니다. id/한글명은 CSV에서 확인하세요.
  - 효과 텍스트와 CSV는 게임 빌드 1.0.29 기준 스냅샷입니다. 밸런스 수치는
    패치마다 바뀌므로, 인용하는 페이지에는 빌드 버전을 함께 적어 주세요.
  - "Icons"는 투명 스프라이트, "Framed"는 패치노트처럼 등급 테두리+배경이 있는
    버전입니다.
  - 확대는 nearest-neighbour라 픽셀이 뭉개지지 않습니다.

로고 사용 규칙
  - 로고 주변 여백을 확보하고 잘라내지 마세요.
  - 색 변경/늘이기/회전/효과 추가/워드마크 재제작 금지.
  - 폰트는 미포함입니다 -- 이름·출처는 Brand/Fonts_KR.txt 참고.
